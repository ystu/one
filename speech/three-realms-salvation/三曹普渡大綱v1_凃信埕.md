主題：三曹普渡
一、白陽普渡的殊勝因緣
（一）三期應運大開普渡之門
1. 青紅白陽三期：白陽由彌勒掌天盤、師尊師母掌道盤
2. 紅陽先修後得、回天者少；白陽慈悲普渡、先得後修
3. 道降火宅：一般人也能在家修道，得明師指點、回歸理天
4. 得道後修心改過、行功立德，珍惜因緣以求成道
5. 普渡由人間擴及氣天諸仙、幽冥眾生，同脫輪迴
（二）三曹範圍與普渡意義
1. 三曹皆待脫輪迴：天曹氣天仙、人曹世人、地曹幽冥
2. 普為廣渡三曹，渡為超凡入聖、脫輪迴回理天
3. 《太上無極混元真經》上渡仙、中渡人、下渡幽冥
4. 關心親人之心擴及眾生，學菩薩慈悲、接引陪伴
5. 認識三曹不同處境，把握人身修道助人的機會
二、三曹眾生的處境與救渡
（一）上渡天曹眾生超氣入理
1. 苦修未遇明師、忠孝行善者，善行可敬而得人天福報
2. 氣天福盡仍須輪迴，須得道修持、超氣入理，才能超生了死
3. 氣天仙助道立德、條件具足，仍須託有緣人引保求道
4. 氣天仙待人引保，人身能親聽、親問、改過，更應珍惜
（二）中渡人曹眾生明性修真
1. 佛陀指甲土比大地土：再得人身者少，把握聽道改過助人
2. 明師一指點明本性，憑良心處理利益與人際關係、反省改過
3. 借假修真：藉身修性，以口講道、手腳助道、共事磨性
4. 道理落實家庭、工作與待人處事，珍惜人身修道便利
5. 在世者能親自學修，過世親人的得渡因緣
（三）下渡地曹眾生離苦超昇
1. 上天恩准陰陽齊渡，修心立德有機會超拔父母祖先
2. 師尊愿渡百人報親恩，渡至六十四人仍憂父苦，孝心感天蒙准超拔
3. 渡人重誠心孝心、盼人學好，自己改過而不計較人數功德
4. 《孝經》愛惜身體、立身行道：在世盡孝、身後修道培德報恩
5. 幽冥眾生感恩懺悔助道，人曹少計較、多改過，共助三曹得渡
（四）人曹承擔普渡收圓使命
1. 言語講道、行動示範，前賢陪我學、我再陪人學，代代相傳
2. 成全是陪人學道修道，從自學、關心人與幫忙道務做起
3. 臺灣傳道艱難，師母承考不出門、半夜叩首、病中念眾生，以關懷傳道報恩
4. 普渡收圓是助眾生得道修道回理天，從自身修辦盡一份力
三、修辦了愿共助普渡收圓
（一）得道是修辦與成道的起點
1. 先得後修：先求道，再改過、修心立德，持續修辦以求成道
2. 夏盛珍老前人求道後苦熬二十天戒鴉片，立愿清口茹素、赴哈爾濱開荒
3. 依師尊慈示改過修心、行功立德、弘道渡人了愿，內修外辦並進
（二）內修心性與外辦道務並進
1. 內修反省用心與動機，改掉貪心、脾氣與計較
2. 《六祖壇經》自心眾生無邊誓願渡：管好念頭、讓良心作主
3. 外辦渡人成全、參與道務，將所學付諸行動
4. 共事磨性：好好說話、放下得失、不爭功名，守住學道助人了愿的初心
5. 聖凡兼修：用心修道、盡家庭工作本分，常省改過盡責、持續實踐
（三）珍惜因緣真心盡責了愿
1. 等家業安頓容易一再拖延，依師尊提醒把握今生人身道緣、不待來生
2. 把握今天：家庭盡責、學理改過、盡心助道，從能做之事共助師尊師母普渡
3. 了愿是實踐所愿：順境感恩、逆境學習、合作改過、承擔盡責
4. 佛陀指土珍惜人身、師尊孝親行動報恩、夏老改習開荒、師母護道慈悲
