主題：真道真考見真心
一、逆境不氣餒，學習積極面對困難
（一）人生每天都有考試
1. 期中考經驗：平常覺得都懂，一上考場才發現不會；被主管念、跟室友吵架、努力沒有結果，都是人生的考題
2. 修道後考題沒有變少：困難是人生常態，不能因此否定修道的幫助；孟子「天將降大任於是人也」，考題多是因為正在成長
3. 真道真考見真心：道是真的，考驗也是真的，考驗會照出我們真正的心
4. 逆境如何守住、順境如何不迷失、平常如何準備，才能通過人生的考驗
（二）孔子困於陳蔡，三位弟子的不同心態
1. 《孔子家語．在厄》：孔子困於陳蔡、絕糧七日，仍講誦弦歌，以同一問題詢問三位弟子
2. 子路懷疑有德者為何受困；孔子以「君子修道立德，不謂窮困而改節」提醒他守住節操
3. 子貢建議降低要求以求世人接納；孔子提醒應修好自己的道，不是為了讓別人接受而改變
4. 顏回認為「不容然後見君子」，孔子欣然認同；受挫時，自己比較像子路、子貢，還是顏回？
（三）困境磨練心志，增長能力
1. 孟子「必先苦其心志，勞其筋骨，餓其體膚，空乏其身，行拂亂其所為，所以動心忍性，曾益其所不能」：困境提醒不足、磨練心志
2. 河裡的石頭經過無數滾動打磨才變得圓滑；在考驗中磨練心性，面對人事物才能圓滿
3. 回到眼前的困難：即使處境尚未好轉，仍願意調整心態、反省學習、尋找方法，守住道理繼續努力
二、順境不自滿，感恩惜福、戒慎恐懼
（一）生於憂患，死於安樂
1. 孟子「然後知生於憂患，而死於安樂也」：憂患讓人奮起，安逸反而容易讓人迷失
2. 工作順利、生活安定、身邊有人支持：順境值得感恩，卻容易驕傲、懈怠，有時比逆境的考驗更大
（二）農夫與悉達多太子面對順境的選擇
1. 農夫寓言：牛與午餐被偷，仍設法耕作、體諒他人；第三個小鬼助他避水患、經商致富，農夫卻沉迷享樂、苛待僕人
2. 小鬼：「我只不過讓他擁有超過他所求的財富」，貪婪的本性就完全顯露
3. 悉達多太子：淨飯王以宮殿享樂留住王子；出城見老、病、死與修行人，夜半離宮，放下王位與安逸出家求道
4. 同樣什麼都不缺，農夫被財富綁住，悉達多在舒適中看見更重要的事；差別不在條件，而在心
（三）感恩惜福，戒慎恐懼
1. 生活順遂、道場環境熟悉時，自省是否懈怠；不是要放下一切，而是用眼前的好條件學習、付出，渡人成全人
2. 感恩惜福、珍惜因緣，保持謙卑與自省
3. 戒慎恐懼是謹慎自己的心念與言行，不是膽戰心驚擔心出事；可以安心歡喜地生活，也繼續用功
4. 同樣的處境，為什麼有人守得住、有人守不住？考試考得好靠平常讀書，考驗過得去靠平常修持
三、把每次考驗化為修心的機會
（一）有做不等於修到心
1. 修得對不對，不看做了多少，而看遇事時心有沒有改變；常到佛堂，遇事仍計較、發脾氣，是有做而沒有修到心
2. 孟子「人恆過，然後能改」：遇到難相處的同學，第一念是「他怎麼這樣」，停下來才看見自己的不耐煩與計較；看見習氣，才知道要修什麼
（二）行功了愿，在付出中改變習氣
1. 「布施度慳貪」：從願意付出做起，練習減少貪求與捨不得
2. 多行功了愿，可以消冤解孽、停止惡性循環，在實際付出中改進自己
（三）落實三不離：好的環境、對的人、對的方法
1. 要順利畢業、考出好成績，須在教室裡學習，有對的老師同學，用對的教材
2. 不離佛堂如同教室：常親近修辦環境，被道場文化薰習，讓平日的學習成為遇事時的力量
3. 不離前賢如同老師同學：迷失或信心動搖時，有人提醒與陪伴；師尊師母與前輩在戰亂、禁制中仍堅持修辦，今日的道場來自他們的付出
4. 不離經典如同教材：以聖賢的教誨校正自己的想法，堅定修道的信心
（四）以感恩的心準備下一場考試
1. 眼前看起來不順的事，不一定是壞事；用感恩的心看待，常能從中學到東西
2. 回顧自己目前的順境或逆境，選定一項今天就能開始的修持：練習付出、向前賢請益，或從經典校正想法
3. 人生每天都有考試，考試不可怕，可怕的是沒準備；遇到挫折守住道理，日子順了還願意付出，看見毛病願意改正，這就是真道真考見真心
