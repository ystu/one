# 老師的話簡報製作規則

第一次使用：《老師的話（第九輯）》〈苟日新，又日新〉第129～131頁（2026-11-21）

## 一、流程

1. 拍下書頁照片，按原書逐字轉成繁體文字，這份轉寫就是**原文**。
2. 準備講稿：每個 `#` 是一段原文的開頭，後面接自己寫的**白話說明**。
3. 依照下面的規則排成簡報。
4. 校對完成後列出改過的錯字，交給講者確認。

## 二、內容規則

- 原文一律以書上的轉寫為準。
- 不標「第X段」。
- 白話說明照講稿原文，一段一段呈現：
  - 不另外抽標題、標重點，不做卡片或摘要。
  - 不增加、不改寫內容，**只改錯字**，並把半形標點 `.` `,` `?` 改成全形 `。` `，` `？`。
- 段落開頭「幾個字＋冒號」的地方用**粗體**，冒號也一起加粗（例如：**六祖云：**、**貪：**、**調伏貪心：**）。冒號在句子結尾的不加粗（例如「而得道更有四大難：」）。
- 講稿裡放的圖片照樣保留（例如「活佛師尊慈語」圖）。

## 三、排版規則

| 項目 | 設定 |
|---|---|
| 版面 | 16:9（1920×1080），四周留白約 112～128px |
| 原文 | 藍色 `#1A4B8C`，字體 Noto Serif TC（思源宋體），58 號，行距 1.75，左側一條 8px 藍線 |
| 白話說明 | 黑色 `#1E1E1E`，字體 Noto Sans TC（思源黑體），56 號，行距 1.7 |
| 對齊 | 左右對齊（text-align: justify），整塊文字上下置中 |
| 內頁背景 | 米白色 `#FAF7F0` |
| 封面／結尾背景 | 深藍色 `#16325C`，小字金色 `#D9C9A3`，大字米白色 |

- 一頁放一段，分頁清楚，方便上台講。
- 原文太長的段落，在句子結束處拆成兩頁。
- 白話說明如果一頁有點塞不下，縮小行距和上下留白，**維持在同一頁**，不拆頁。

## 四、封面

```
老師的話（第X輯）
〈篇名〉
第XXX～XXX頁
────
後學　林進輝　敬上
```

## 五、結尾頁

```
祝各位前賢
法喜充滿
聖凡如意
身體健康
────
謝謝大家
```

## 六、分享與播放

- 最穩定：用簡報連結全螢幕播放，另外匯出一份 PDF 備用。
- 匯出 PowerPoint 時，電腦沒有安裝思源宋體／思源黑體的話會換字體，排版可能跑掉。
