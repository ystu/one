# 會議紀錄整理規則

## 一、整理前先確認資料

整理會議紀錄前，先確認同一目錄下可參考的資料。

必要資料：

1. 會議逐字稿或錄音轉文字檔
2. 同目錄下的會議附件、企劃書、課程表、報告資料
3. `meeting/專有名詞表.md`
4. 既有的會議紀錄成品或前次會議紀錄

使用順序：

1. 先讀 `meeting/專有名詞表.md`
2. 再讀同目錄下與會議相關的 `.md` 檔
3. 再讀逐字稿
4. 最後整理正式會議紀錄

若逐字稿與附件內容不一致，先以會議中最新討論為主；若是日期、時間、地點、人名、課程名稱等固定資訊，優先用附件或已確認資料校正。

## 二、語音辨識錯字校正

語音辨識常會把人名、稱謂、道場用語、活動名稱辨識錯誤。整理時不可直接照抄逐字稿，應先做專有名詞校正。

校正原則：

1. `meeting/專有名詞表.md` 的「錯誤辨識／正確用詞」為第一優先
2. 同目錄附件中的正式名稱為第二優先
3. 同一份逐字稿中反覆出現、語境明確的詞，可依上下文修正
4. 無法確認的人名、負責人或分工，不要硬改成確定語氣
5. 不確定的資訊可寫「會中提及」「後續仍需確認」

常見校正類型：

| 類型 | 整理方式 |
| --- | --- |
| 人名與稱謂 | 依 `專有名詞表` 和附件修正，例如講師、學長、點傳師 |
| 會議名稱 | 依附件或會議開場正式名稱修正 |
| 活動名稱 | 依企劃書、課程表、海報資料修正 |
| 道場用語 | 依常用正式寫法修正，例如「後學」「前人」「處長慈悲」 |
| 時間地點 | 依附件表格校正，避免逐字稿誤辨 |
| 主題標語 | 依正式企劃文字保留標點與用字 |

## 三、整理目標

正式會議紀錄不是逐字稿摘要，而是可供會後追蹤的工作文件。

整理時要做到：

1. 保留會議結論、共識、提醒與待辦
2. 刪除寒暄、重複、語助詞、口誤與現場停頓
3. 把口語討論整理成清楚條列
4. 把概念性討論轉成可執行事項
5. 把不確定事項標示為需確認
6. 讓未參會者也能理解背景、決議與下一步

避免：

1. 逐字照抄發言
2. 把尚未決定的內容寫成決議
3. 只寫活動概念，沒有補上時間、人力、場地、期限
4. 遺漏處長、副處長、專員或負責人給出的提醒
5. 未校正專有名詞就輸出正式紀錄

## 四、標準架構

會議紀錄建議使用以下架構：

```md
# 會議紀錄標題

## 基本資料

- 會議名稱：
- 會議日期：
- 會議方式：
- 會議地點：
- 相關活動日期：
- 相關活動地點：
- 主題：

## 會議重點摘要

1.
2.
3.

## 討論事項

### 一、議題名稱

- 討論重點：
- 會中提醒：
- 後續需確認：

## 決議與共識

1.
2.
3.

## 待辦事項

| 項目 | 負責人／團隊 | 期限 | 備註 |
| --- | --- | --- | --- |
|  |  |  |  |

## 下次會議準備方向

- 

## 其他提醒

- 
```

可依會議性質增減章節，但「基本資料」「重點摘要」「討論事項」「決議與共識」「待辦事項」應盡量保留。

## 五、基本資料整理

基本資料要使用正式名稱，並盡量從附件、會議通知或課程表確認。

整理項目：

1. 會議名稱
2. 會議日期
3. 會議方式或地點
4. 活動日期
5. 活動地點
6. 活動主題
7. 主要對象或班別

日期格式建議：

1. 西元日期：`2026年5月19日`
2. 民國活動日期可保留：`民國115年7月11日至7月12日`
3. 若同時需要辨識年度，可寫：`民國115年（2026年）`

## 六、會議重點摘要

摘要放在前面，讓讀者先掌握整場會議結論。

摘要規則：

1. 以 5 到 8 點為原則
2. 每一點只寫一個重點
3. 優先寫決議、期限、需補件事項、下次會議前任務
4. 不放太多討論細節
5. 不寫發言者逐字內容

摘要句型：

```md
1. 文書小組預計於5月下旬完成宣傳海報，並送請處長、副處長審核。
2. 各活動需於下次會議前提出細項企劃，包含時間、場地、人力與流程。
3. 手冊資料須於6月22日前提供 Word 檔，以利文書小組編輯與印刷。
```

## 七、討論事項整理

討論事項應依議程或會議實際進行順序整理。

每一個議題可分成：

1. 已確認事項
2. 規劃方向
3. 會中提醒
4. 後續需補強
5. 待確認問題

寫法範例：

```md
### 一、文書小組進度

- 宣傳海報預計於5月下旬完成。
- 完成後將與報名表一併呈處長、副處長審核。
- 下次會議需提供手冊封面、封底設計。
```

若議題包含多個活動，可用次標題拆開：

```md
### 三、大專成長營活動規劃

#### 1. 7月11日活動：有難．我來擔

- 時間：
- 地點：
- 負責團隊：
- 規劃方向：
- 會中提醒：
```

## 八、決議與共識整理

決議與共識要寫「會議已形成的方向」，不要混入尚未確認的猜測。

可列入決議的內容：

1. 已確認的活動方向
2. 已確認的期限
3. 已確認的提交方式
4. 已確認的下次會議準備項目
5. 經處長、副處長或會議主持人明確提醒後，大家同意執行的事項

不宜列入決議的內容：

1. 某位發言者臨時想到、尚未討論的構想
2. 負責人尚未確認的人力安排
3. 時間地點仍未定案的內容
4. 語音辨識無法判斷的片段

若方向可行但需補細節，可寫：

```md
1. 大專兩個主要活動方向原則可行，請活動規劃者於下次會議提出完整細項企劃。
```

## 九、待辦事項整理

待辦事項要能被追蹤，建議用表格呈現。

欄位固定為：

| 項目 | 負責人／團隊 | 期限 | 備註 |
| --- | --- | --- | --- |

整理原則：

1. 每一列只放一個可完成的任務
2. 負責人不明時，寫負責團隊或「待確認」
3. 期限不明時，依會議語境寫「下次會議前」「營隊前」或「待確認」
4. 備註欄補充交付形式、注意事項、相關對象
5. 概念性提醒若不能追蹤，不放待辦表，改放「下次會議準備方向」

待辦句型：

```md
| 完成宣傳海報 | 文書小組 | 5月下旬 | 完成後呈處長、副處長審核 |
| 補齊活動細項企劃 | 活動小組 | 下次會議 | 含流程、場地、人力與物資 |
```

## 十、保留與刪除規則

應保留：

1. 會議名稱、日期、活動資訊
2. 正式議題與報告內容
3. 活動目的、流程、時間、地點、人力
4. 處長、副處長、專員、講師提出的具體提醒
5. 決議、共識、期限、待辦
6. 下次會議前需準備的資料

應刪除或濃縮：

1. 開場寒暄與重複感謝
2. 語助詞、停頓、口誤
3. 發言者反覆解釋同一件事的段落
4. 現場測試麥克風、畫面、連線等內容
5. 與會議任務無關的閒聊
6. 過細且不影響決策的遊戲操作逐字說明

若遊戲或活動規則很複雜，會議紀錄只保留會議層級需要追蹤的資訊：

1. 活動目標
2. 規則是否容易理解
3. 是否需要示範或事前訓練
4. 是否需補完整企劃書
5. 與課程主題如何連結

## 十一、不確定資訊寫法

語音辨識不清或會中未定案時，要避免寫成確定句。

建議用語：

1. `後續仍需確認`
2. `會中提及可能由...負責`
3. `目前尚未提出具體草案`
4. `需再補上完整流程`
5. `建議於下次會議前確認`

避免用語：

1. `已確定由...負責`，除非會中明確確認
2. `決議...`，除非主持人或會議形成共識
3. `必須...`，除非是明確要求或期限

## 十二、引用同目錄資料的方法

同目錄下的 `.md` 檔通常是企劃、附件、課程表或前次資料。整理會議紀錄時要善用這些文件補正逐字稿。

使用方式：

1. 從附件補正正式活動名稱
2. 從課程表補正時間、地點、負責團隊
3. 從企劃書補正活動目的與主題文字
4. 從前次紀錄補正議題延續脈絡
5. 從附件確認專題名稱、講師、操持、服務團隊

但要注意：

1. 附件是會前資料，會議中若有更新，要以會議結論為主
2. 若附件與會議不同，紀錄中可寫「原規劃為...，會中建議調整為...」
3. 不要把附件全文搬進會議紀錄，只摘錄與本次討論有關的資訊

## 十三、語氣與格式

會議紀錄語氣要正式、清楚、可追蹤。

文字規則：

1. 使用書面語，不寫過度口語
2. 條列優先，避免長段落
3. 每點只放一個重點
4. 標題要能看出議題內容
5. 同一層標題格式一致
6. 人名與稱謂前後一致
7. 中英文與數字格式保持一致

標點規則：

1. 中文內文使用全形標點
2. 時間可用 `13:50至17:00` 或 `13:50~17:00`，同一份文件內保持一致
3. 活動名稱可用書名號或冒號，但同類型要一致
4. 表格中內容盡量簡短

## 十四、整理流程

建議按以下流程操作：

1. 讀 `meeting/專有名詞表.md`
2. 讀同目錄所有會議相關 `.md` 檔
3. 快速通讀逐字稿，標出議題段落
4. 依專有名詞表先校正常見錯字
5. 把逐字稿切成議題區塊
6. 每個議題整理成「已確認、提醒、需補強、待確認」
7. 從各議題抽出會議重點摘要
8. 從各議題抽出決議與共識
9. 從各議題抽出待辦事項表
10. 回頭檢查人名、日期、活動名稱、期限
11. 對照附件確認正式用詞
12. 最後檢查是否仍殘留語音辨識錯字

## 十五、完成前檢查清單

完成會議紀錄前，逐項檢查：

1. 是否已先參考 `meeting/專有名詞表.md`
2. 是否已參考同目錄下的會議附件或企劃 `.md` 檔
3. 會議名稱是否正確
4. 日期、時間、地點是否正確
5. 人名、稱謂、講師名稱是否已校正
6. 活動名稱、課程名稱、主題名稱是否使用正式寫法
7. 摘要是否能快速看出會議結論
8. 討論事項是否依議程或實際討論順序排列
9. 決議與共識是否沒有混入未定案內容
10. 待辦事項是否有負責人或團隊
11. 待辦事項是否有期限或追蹤時間點
12. 不確定資訊是否標示「待確認」或「後續需確認」
13. 是否刪除寒暄、重複、語助詞與無關片段
14. 是否保留處長、副處長、專員或講師的具體提醒
15. 是否避免逐字稿式長段落
16. 是否仍有明顯語音辨識錯字

## 十六、整理提示詞範本

可用以下提示詞整理新的會議紀錄：

```md
請根據這份會議逐字稿整理正式會議紀錄。

整理前請先參考：
1. meeting/專有名詞表.md
2. 同一目錄下的會議附件與企劃 md 檔

整理要求：
1. 先依專有名詞表校正語音辨識錯字，特別是人名、稱謂、活動名稱、道場用語。
2. 不逐字照抄，請整理成正式、清楚、可追蹤的會議紀錄。
3. 保留基本資料、會議重點摘要、討論事項、決議與共識、待辦事項、下次會議準備方向。
4. 待辦事項請用表格，欄位為「項目、負責人／團隊、期限、備註」。
5. 對於尚未確認的人名、分工、期限，請寫「待確認」或「後續仍需確認」，不要硬寫成確定。
6. 若逐字稿與附件不同，請以會議中最新討論為主；固定資訊則用附件校正。
7. 完成後請檢查是否還有語音辨識錯字與未校正專有名詞。
```
