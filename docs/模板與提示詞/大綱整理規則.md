# 大綱整理規則

演講準備流程與大綱、講稿的同步規則，統一參照根目錄 `AGENTS.md`；本檔維護大綱的寫法與輸出排版規範。

## 一、最上方必須標明主題

1. Markdown 最上方使用「主題：題目」，只寫核心題目，不編號。
2. 主題不計入標號層級。
3. Word 主題與署名格式依第十一節處理。

## 二、標號層級規則

大綱固定採三層標號，作為可直接帶上台的講述依據：

1. 第一層：國字數字加頓號，如「一、二、三、」。
2. 第二層：全形括號加國字數字，如「（一）（二）（三）」。
3. 第三層：阿拉伯數字加半形句點與空格，如「1. 2. 3.」。
4. 第二層在各大題下重新編號，第三層在各次標題下重新從「1.」開始。
5. 所有講述重點都融入這三層，不另加第四層、無編號內文或 `-` 項目符號。
6. 一張 A4 版也保留三層；除非使用者另有指定，不改為兩層。

## 三、第一層：大標題

1. 標示大段主題與方向，使用「一、大標題」。
2. 大標題之間須有順序推進。
3. 用簡潔的內容語呈現，不寫成完整講述段落。

## 四、第二層：次標題

1. 拆解大題下的主要觀念，使用「（一）次標題」。
2. 比大標題更具體，能看出小段的內容與功能。
3. 同一層語氣與層級一致，不以阿拉伯數字取代。

## 五、第三層：講述重點小標題

1. 使用「1. 重點」，讓講者看到一項就能聯想到完整觀念或故事。
2. 將核心道理、人物、事件、關鍵數字、故事轉折與結果、引文線索及生活實踐直接融入小標題。
3. 同一故事或同一重點原則上整合成一項，不因原稿分成多段就拆成多項。
4. 重複或高度相近的小標題須合併，保留必要資訊，不把標題與相同意思的句子各列一次。
5. 不只堆疊關鍵字，也不抄成長篇口語段落；保留足以喚起講述內容的完整意思。
6. 每組以 3 到 5 項為參考，依內容調整，不為湊數增列或刪去必要線索。

## 六、標題寫法規則

1. 標題須有內容與方向，不只寫「定義」「歷史」「宗旨」等分類名詞。
2. 使用能直接理解的內容語，同層語氣一致。
3. 避免「說明」「介紹」「承接」「帶出」「引導」「收束」等操作指令。
4. 第三層可用冒號、逗號或分號串起同一故事的必要經過，不把無關觀念硬塞成一項。
5. 跨節重複須有實際作用，例如前段交代概念、後段談實踐；只重述相同內容時應合併或刪除。

## 七、內容安排規則

1. 大綱兼具閱讀骨架與上台講述線索，講稿展開完整口語內容。
2. 從既有講稿整理時，依講述順序涵蓋必要內容，以完整觀念或故事整合，不要求一段對應一項。
3. 尚無講稿時，依已查閱資料建立可展開的三層大綱；資料與引文要求參照 `演講風格.md`。
4. 故事可保留人物、事件名稱、關鍵數字、轉折與結果，讓講者能回想內容；不得虛構細節。
5. 經典與人物引述保留名稱、核心引文或意義；改寫不得冒充原話。
6. 提問、比喻與轉場的必要意思融入對應小標題，不另列講者操作說明。
7. 不列問候、開場感恩、結尾請益、道歉、祝福及致謝等固定儀式性內容。
8. 主題本身的結論、實踐方向與必要回顧仍須保留，勿與固定結尾一併刪除。

## 八、每段內部結構

依內容需要，安排問題或處境、核心道理、引證或故事、生活實踐與重點回顧，不必每節硬套相同結構。

同一故事的背景、行動、轉折與結果優先合為一項；只有不同觀念或獨立實踐確有必要時才分列。

## 九、文字長度規則

1. 大標題建議 10 到 25 字，次標題建議 8 到 20 字。
2. 第三層以簡短明確為原則，必要時可加長，以容納完整故事線索與關鍵資訊，不硬限字數而漏掉重點。
3. 不寫成連續多句的講述段落，也不為縮短單項而把同一重點拆成重複項目。
4. 刪除贅語，保留上台能展開內容的資訊密度與可讀性。

## 十、語氣規則

1. 清楚、穩定、簡潔，避免過度修飾與情緒鋪陳。
2. 不使用「我要說明」「這裡要帶到」「接著談」等講者操作語。
3. 保留道理、故事與實踐的關聯，使小標題能喚起內容，並留有口頭展開空間。

## 十一、輸出與排版規則

先以 Markdown 整理；Word 的製作時機依根目錄 `AGENTS.md` 規定。

Markdown 格式：

1. 首行標明主題，後續依三層標號排列。
2. 每項各占一行，全文不留空白行。
3. 不使用 `#` 標題語法或 `-` 項目符號，不在標題下另附無編號段落。
4. 編號連續，合併或刪除後重新編號。

Word 格式：

以 [信愿行大綱_凃信埕v0.docx](../../speech/faith-vow-practice/信愿行大綱_凃信埕v0.docx) 為排版範本；製作時須實際讀取範本的格式設定，優先沿用其樣式、編號與頁面設定。使用者另有指定時，以當次指定為準。

1. 全文使用標楷體，字色為黑色
2. 首行只放主題名稱，不加「主題：」前綴，使用 20 號字、粗體、置中；Markdown 仍保留「主題：」格式
3. 標題下一行放署名「後學 凃信埕 敬述」，使用 12 號字、非粗體、靠右對齊
4. 大標題、次標題與第三層重點均使用 14 號字；大標題不另加粗，以標號與縮排區分層級
5. 保留原本大綱的大題、小題、內容與順序；只套用範本格式，不帶入範本的引文或內文
6. 第一層使用「一、二、三、」，標號靠左，文字起點距正文左邊界約 1.27 公分；第二層使用「（一）（二）（三）」，標號較第一層向右縮排約 0.85 公分，文字接續其後；第三層使用「1. 2. 3.」，較第二層向右縮排，依範本樣式調整；各層換行須對齊該項文字起點，避免標號與文字重疊
7. 優先使用 Word 多層次編號，第二層在各大題下重新從「（一）」開始，第三層在各次標題下重新從「1.」開始；不得同時保留手打標號而產生重複編號
8. 段前、段後不額外加大間距，不插入多餘空白段落；行距與格線沿用範本，保留 18 點的文件行格線（`w:linePitch="360"`），不得只設定單行距而忽略格線對實際行高的影響
9. 字元間距沿用對應範本段落：標題、署名及一般內文加寬 1 點，大標題使用範本原有設定
10. 使用 A4 直式、單欄；上、下邊界各 2.54 公分，左、右邊界各 3.175 公分
11. 保持範本的簡潔版面，不額外加入裝飾線、色塊或複雜樣式
12. 完成後核對來源內容、字型、字級、對齊、縮排、編號及頁面設定；可使用 Word 或可用的文件轉譯工具檢查實際版面，確認無缺字、重疊或不合理分頁；無法完成視覺檢查時，須在交付時說明

Word 一張 A4 版：

1. 先刪除多餘空白與重複內容，精簡用字，保留三層結構及必要講述線索。
2. 先沿用範本邊界，仍超頁時可使用窄邊界。
3. 保留標楷體、標題 20 號、署名 12 號、內文 14 號，不縮小字體硬塞。
4. 段前段後距離可調小，但保留閱讀空間；除非另有要求，採單欄。
5. 若保留必要內容仍無法容納一頁，說明篇幅限制與需取捨的內容，不自行取消第三層或刪去關鍵資訊。

## 十二、檔名命名規則

大綱檔案統一使用以下格式命名：

```md
{題目}大綱_凃信埕
```

規則：

1. `{題目}` 使用該篇大綱的主題名稱
2. 題目後直接接「大綱」
3. 「大綱」後接底線 `_`
4. 底線後接姓名「凃信埕」
5. 不額外加入日期、版本號或其他文字，除非另有要求

Markdown 檔案範例：

```md
認識一貫道大綱_凃信埕.md
信愿行大綱_凃信埕.md
修道的好處大綱_凃信埕.md
```

Word 檔案範例：

```md
認識一貫道大綱_凃信埕.docx
信愿行大綱_凃信埕.docx
修道的好處大綱_凃信埕.docx
```

Markdown 大綱使用 `.md`，Word 檔使用 `.docx`，檔名主體一致。

## 十三、檢查規則

1. 首行是否標明主題，後續是否完整使用三層標號。
2. 是否沒有項目符號、第四層、無編號內文及空白行。
3. 各層編號是否連續，第二、三層是否在所屬上層重新編號。
4. 大題與小題是否有順序推進，並依 `AGENTS.md` 完成與講稿的同步核對。
5. 必要道理、引證、故事線索與實踐是否充分，能否只帶大綱上台展開。
6. 同一故事或相近重點是否合併，是否避免標題與內容重複。
7. 是否保留有來源的人物、事件、關鍵數字、轉折與結果，且沒有虛構。
8. 是否移除固定開場感恩、結尾請益祝福，同時保留主題結論與實踐。
9. 是否用內容語呈現，而非逐字稿或講者操作指令。
10. 檔名、Word 格式及一張 A4 需求是否符合第十一、十二節。

## 十四、標準格式範例

```md
主題：題目
一、大標題
（一）次標題
1. 核心道理與必要解釋
2. 故事人物、關鍵經過與結果所呈現的觀念
3. 生活實踐與行動方向
（二）次標題
1. 具體觀念與引證線索
2. 必要實踐重點
二、大標題
（一）次標題
1. 核心道理與講述線索
2. 主題結論與實踐方向
```

## 十五、一張 A4 版

沿用第十四節三層格式，依第十一節精簡重複內容與版面；每項保留足以回想講述內容的線索，不改成只有兩層的閱讀骨架。
