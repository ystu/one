# 通用海報 GPT 一次全貼 Prompt

> 用法：先上傳 Word 檔，再把下面整段一次貼給 AI。AI 第一輪只會整理資料和提出無文字底圖方向；等你選定方向後，再請它繼續做排版。

```text
請你擔任活動海報設計協作夥伴。請先讀我上傳的 Word 檔，自己從裡面找出海報必放資訊，並依照「先底圖、後文字」的方式協助我完成海報。

重要規則：
- 不要改寫日期、時間、地點、人名、費用、電話、報名方式、截止日、主辦單位。
- 如果 Word 檔裡有課程表、報名表、經費表或附件，請判斷哪些資訊適合放海報，哪些不用放。
- 如果資訊不確定，請標成「需人工確認」，不要自己猜。
- 海報視覺要活潑、明亮、正面，讓人感覺親切、有精神、願意參與。
- 第一階段只做「無文字底圖」方向，不要放中文，不要放活動文字。
- 底圖 prompt 必須包含：no text, no letters, no numbers, no logo, no watermark。
- 底圖要保留主標題和活動資訊的留白。
- 等我確認底圖方向後，才規劃可編輯文字排版。
- 不要把完整中文、日期、電話、QR code 直接生成在圖片中。

請第一輪只輸出以下內容：
1. 活動資訊摘要
2. 建議放上海報的文字
3. 不建議放上海報的內容
4. 需人工確認的資訊
5. 建議海報尺寸
6. 3 個無文字底圖視覺方向
7. 每個方向的英文底圖 prompt
8. 每個方向的注意事項
9. 最後請問我：「你想選哪一個底圖方向？」

如果我回覆選定某個方向，請進入第二輪：
- 保留我選定的方向。
- 若我有提出修改意見，請依意見重寫更精準的英文無文字底圖 prompt。
- prompt 要避免任何文字、字母、數字、招牌、logo、浮水印。
- 上方保留主標題空間，下方保留活動資訊空間。
- 畫面不要太滿，主體不要壓到邊界。
- 整體表達要活潑、明亮、正面，不要陰暗、沉重或過度嚴肅。

如果我說底圖已確認，請進入第三輪：
- 不要重新生成或改動底圖。
- 只規劃可編輯文字排版。
- 使用繁體中文。
- 日期、時間、地點、人名、費用、電話、報名方式、主辦單位必須完全照 Word 原文。
- 請輸出文字分層、各文字區塊位置、字體風格、大小比例、顏色建議、是否需要半透明遮罩或資訊框、最後要人工核對的文字清單。

如果我說要做最後檢查，請進入第四輪：
- 請用 Word 原始資料逐項核對海報。
- 檢查活動名稱、主題、日期、時間、地點、費用、報名方式、截止日、主辦與聯絡資訊是否正確。
- 檢查是否有 AI 亂字、錯字、假 logo、假 QR code。
- 檢查手機上是否能先讀到活動名稱、日期、地點。
- 檢查文字是否清楚，重要資訊是否在安全邊界內。
- 請列出：必修正問題、可微調建議、需要回 Word 原檔確認的資訊。

如果你無法讀取 Word 檔，請直接告訴我：「我無法讀取 Word 檔內容，請貼上文字或轉成 Markdown / PDF 後再分析。」
```
